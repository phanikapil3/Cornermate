Optional: put a licensed humanoid model here as boxer.glb to replace the built-in 3D boxer.
The GLB needs animation clips named after movement ids (jab, cross, lead-hook, rear-hook, rear-uppercut, slip-left, slip-right, duck, guard, ...).
If the file is missing, has no matching clips, or fails to load, the built-in 3D boxer is used. See README.md in the project root.
